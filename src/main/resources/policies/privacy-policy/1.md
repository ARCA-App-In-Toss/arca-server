ARCA 운영자(이하 "운영자")는 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고 관련 고충을 처리하기 위해 다음과 같이 개인정보처리방침을 둡니다.

## 1. 개인정보의 처리 목적

운영자는 다음 목적으로만 개인정보를 처리합니다.

1. 회원 식별과 가입, 로그인 유지: 서비스 이용계약의 체결과 이행 (「개인정보 보호법」 제15조 제1항 제4호)
2. 질문 제공과 답변 저장, 조회, 수정, 삭제: 서비스 이용계약의 이행 (같은 법 제15조 제1항 제4호)
3. 약관 동의 기록과 그 입증: 운영자의 정당한 이익 (같은 법 제15조 제1항 제6호)
4. 서비스 이용 현황 분석과 개선: 운영자의 정당한 이익 (같은 법 제15조 제1항 제6호). 분석에는 답변 본문과 닉네임을 쓰지 않습니다.

## 2. 처리하는 개인정보 항목

운영자는 이름, 전화번호, 이메일, 생년월일을 받지 않습니다.

**회원 가입과 서비스 이용 시**

- 토스 익명 식별값: 앱인토스가 제공하는 값입니다. 원문은 저장하지 않고 복원할 수 없는 해시값만 저장합니다.
- 회원 코드: 운영자가 배정합니다.
- 닉네임: 회원이 설정한 경우에만 처리합니다.
- 답변: 답변 본문, 고른 질문, 작성 시각, 수정 시각
- 약관 동의 기록: 약관 종류, 버전, 동의 시각

**자동으로 생성되는 정보**

- 로그인 기록: 로그인 토큰의 해시값, 발급 시각, 만료 시각
- 서비스 이용 기록: 화면 방문, 버튼 사용 같은 이용 이벤트의 종류, 발생 시각, 앱 버전, 기기 운영체제

**수집 방법**

- 앱인토스 플랫폼에서 토스 익명 식별값을 전달받습니다.
- 회원이 서비스 화면에서 직접 입력합니다.
- 서비스 이용 중 자동으로 생성됩니다.

## 3. 개인정보의 보유와 이용 기간

1. 회원 정보, 답변, 약관 동의 기록, 로그인 기록: 회원이 모든 데이터를 삭제할 때까지 보유하고, 삭제 요청 즉시 파기합니다.
2. 서비스 이용 기록: 수집일부터 90일 동안 보유한 뒤 파기합니다. 모든 데이터 삭제를 요청하면 기간과 관계없이 즉시 파기합니다. 개인을 알아볼 수 없게 날짜별 횟수로 합친 통계는 계속 보관할 수 있습니다.
3. 약관 동의 증빙: 모든 데이터 삭제 뒤에도 동의 사실을 입증하기 위해 약관 종류, 버전, 동의 시각, 삭제 시각, 토스 익명 식별값의 해시값만 분리해 보관하고, 삭제 시각부터 1년이 지나면 파기합니다. 답변, 닉네임, 회원 코드는 포함하지 않습니다.
4. 백업: 장애 복구용 백업에 삭제된 정보가 남을 수 있습니다. 백업은 삭제 요청일부터 최대 30일 안에 만료되며, 삭제된 정보를 되살리는 데 쓰지 않습니다.

## 4. 개인정보의 파기 절차와 방법

1. 보유 기간이 끝나거나 처리 목적을 이루면 지체 없이 파기합니다.
2. 전자 파일 형태의 정보는 복구할 수 없는 방법으로 삭제합니다.
3. 운영자는 종이 문서 형태로 개인정보를 보관하지 않습니다.

## 5. 개인정보의 제3자 제공

운영자는 개인정보를 제3자에게 제공하지 않습니다. 다만 법령에 특별한 규정이 있는 경우는 예외입니다.

## 6. 개인정보 처리의 위탁

운영자는 개인정보 처리를 외부에 위탁하지 않습니다.

## 7. 개인정보의 국외 이전

운영자는 개인정보를 국외로 이전하지 않습니다.

## 8. 정보주체의 권리와 행사 방법

1. 회원은 언제든 직접 또는 대리인을 통해 자신의 개인정보 열람, 정정, 삭제, 처리정지를 요구할 수 있습니다.
2. 닉네임은 서비스 안에서 직접 바꾸거나 지울 수 있습니다. 답변은 서비스 안에서 직접 보고, 수정하고, 삭제할 수 있습니다.
3. 서비스 안의 모든 데이터 삭제 기능으로 개인정보 삭제와 탈퇴를 한 번에 요청할 수 있습니다.
4. 그 밖의 요구는 아래 개인정보 보호책임자에게 이메일로 보내 주세요. 운영자는 10일 안에 처리 결과를 알립니다.

## 9. 개인정보의 안전성 확보 조치

1. 토스 익명 식별값과 로그인 토큰은 원문을 저장하지 않고 해시값만 저장합니다.
2. 서버와 앱 사이의 통신은 암호화합니다.
3. 데이터베이스 접근 권한을 운영자로 제한합니다.
4. 서비스 로그에 답변 본문과 질문 원문을 남기지 않습니다.

## 10. 자동 수집 장치

운영자는 쿠키를 사용하지 않습니다. 서비스 개선을 위해 2항의 서비스 이용 기록을 수집하며, 이 기록에는 답변 본문이나 닉네임이 포함되지 않습니다.

## 11. 기기 안에서만 처리하는 정보

작성 중인 답변의 임시 저장 글은 이용자의 기기 안에만 저장되고 운영자의 서버로 보내지 않습니다. 임시 저장 글은 답변을 저장하거나 기기에서 앱 데이터를 지우면 삭제됩니다.
