# 오늘의 질문 (question)

## SEMA와 날짜 편성

- SEMA 하나는 기본 질문 1개와 대체 질문 1개로 이뤄진다
- KST 날짜마다 SEMA가 하나 편성된다. 한 SEMA를 여러 날짜에 다시 쓰지 않는다. 날짜가 없는 SEMA는 예비다
- 배포 단위 ID(`dailySemaId`)는 편성 날짜(`YYYY-MM-DD`)다. 클라이언트는 이 값을 해석하지 않는다
- 같은 날짜에는 모든 회원이 같은 SEMA를 받는다. 개인화와 무작위는 없다
- 예비 SEMA로 교체하면 그 날짜가 예비 SEMA로 옮겨 간다. 배포 단위 ID는 그대로이고 콘텐츠 ID(`semaId`)와 버전이 바뀐다. 교체 도구는 아직 없다
- 질문 원문을 고치면 질문 버전이 오른다. 이미 저장된 답변의 질문 스냅샷은 바뀌지 않는다 (답변 정책은 답변 도메인에서 다룬다)
- 질문의 주제, 난이도 같은 내부 메타데이터는 아직 두지 않는다. 생겨도 응답에는 넣지 않는다

## 오늘 조회

- 허용 세션 mode는 `ACTIVE`다. `GUEST` 세션은 `403 SESSION_SCOPE_INSUFFICIENT`다
- 오늘은 서버가 요청을 받은 시점의 KST 날짜다. 클라이언트 날짜를 받지 않는다
- 미응답이면 오늘 SEMA의 두 질문을 모두 돌려준다. 어느 질문을 먼저 보여줄지는 클라이언트가 정한다
- 활성 답변 수는 지금 남아 있는 답변 수다. 쓰면 1 오르고 지우면 1 내려가며 수정은 바꾸지 않는다. 누적 작성 수나 첫 사용 여부가 아니다
- 답변 도메인이 생기기 전까지 답변 상태는 항상 `UNANSWERED`, 활성 답변 수는 0이다
- 오늘 날짜에 편성된 SEMA가 없는 상태는 운영상 생기지 않는다고 전제한다. 생기면 `503 SEMA_NOT_FOUND`로 응답한다
- 조회는 데이터를 만들지 않는다
